# DSU Website

## Project Description
DSU Website is a responsive web application developed for providing university/college related information in an organized way.  
The website contains pages like Home, About, Courses, Contact, and other student-related sections.

The main objective of this project is to create a user-friendly and attractive educational website using web technologies.

---

## Features
- Responsive Website Design
- Easy Navigation
- Student-Friendly Interface
- Course Information Section
- Contact Page
- Clean and Simple UI

---

## Technologies Used
- HTML
- CSS
- JavaScript
